# Web Pen - Red

任意のウェブページ上に**赤いペン**で自由に描き込みができる、最小構成の Chrome 拡張機能（Manifest V3）。

操作は **ペン / カーソル / 全消去 / 終了** の 4 ボタンのみ。色や線の太さの変更、図形描画、保存・共有機能はありません。

## 機能

| ボタン | 動作 |
| --- | --- |
| ✏️ ペン | ペンモード ON。マウスドラッグで赤い線（#FF0000）を描画 |
| ➤ カーソル | ペンモード OFF。通常どおりページを操作できる（描いた線は残る） |
| 🗑 全消去 | そのページに描いた線をすべて消去 |
| ✕ 終了 | オーバーレイとツールバーをそのタブから完全に除去 |

- 描いた線はページのスクロールに追従します。
- ペンモード OFF のときはオーバーレイが入力を一切受け取らないため、ページ操作を完全に透過します。
- ペンモード中もマウスホイールでのスクロールは可能です。
- ツールバーはドラッグで好きな位置に移動できます（ボタンの上からドラッグしても誤作動しません）。

### ショートカット

| 操作 | 動作 |
| --- | --- |
| **Tab** | ペン ⇄ カーソルを切り替え |
| **右クリック**（ペンモード中） | 即座に全消去（確認ダイアログなし・取り消し不可） |

- カーソルモード中の右クリックは、通常どおりブラウザのメニューが開きます。
- Tab は、**入力欄（input / textarea / 編集可能領域）にカーソルがあるときは横取りしません**。フォームの入力とタブ移動はそのまま使えます。Shift+Tab や Ctrl+Tab などの修飾キー付きも同様に素通しします。
- ツールバーを閉じている / 非表示にしている間は Tab は無効です。

## Chrome への導入方法

Chrome ウェブストアには公開していないため、**フォルダを直接読み込む**形でインストールします。所要 1 分ほどです。

### 1. ファイルを入手する

**ZIP でダウンロードする場合（Git 不要・おすすめ）**

1. このページ右上の緑色の **`< > Code`** ボタン → **Download ZIP** をクリック
2. ダウンロードした `web-pen-red-main.zip` を右クリック →「すべて展開」（Mac はダブルクリック）
3. 展開してできたフォルダを、あとで消さない場所（例: `ドキュメント` の中）に置く
   - **注意**: 読み込んだあとにこのフォルダを移動・削除すると拡張機能が動かなくなります

**Git を使う場合**

```bash
git clone https://github.com/nolozy/web-pen-red.git
```

### 2. Chrome に読み込む

1. Chrome のアドレスバーに `chrome://extensions` と入力して開く
2. 画面右上の **デベロッパーモード** のスイッチを ON にする
3. 左上に現れる **パッケージ化されていない拡張機能を読み込む** をクリック
4. 手順 1 で用意したフォルダを選択する
   - `manifest.json` が直接入っている階層を選んでください。ZIP を展開した場合、フォルダが二重（`web-pen-red-main` の中にもう一つ）になっていることがあります
5. 一覧に **Web Pen - Red** が表示されれば完了

### 3. ツールバーに固定する（任意）

Chrome 右上のパズルピースのアイコン 🧩 をクリックし、**Web Pen - Red** の横のピン留めアイコンを押すと、ツールバーに常時表示されて使いやすくなります。

> デベロッパーモードが ON の間、Chrome 起動時に「デベロッパーモードの拡張機能を無効にする」旨の確認が出ることがありますが、「キャンセル」を選べばそのまま使えます。

## 使い方

1. 描き込みたいページを開く
2. ツールバーの拡張機能アイコン **Web Pen - Red** をクリック → 画面右上にミニツールバーが表示され、ペンモードで起動します
3. ドラッグして描画。ページを操作したいときは ➤ カーソル（または **Tab**）、消すときは 🗑 か**右クリック**、閉じるときは ✕
4. 拡張機能アイコンをもう一度クリックすると、ミニツールバーの表示 / 非表示を切り替えられます（✕ で閉じた場合は再度クリックで作り直されます）

> `chrome://` などの Chrome 内部ページ、Chrome ウェブストア、PDF ビューアでは、Chrome の仕様上 content script を実行できないため動作しません。

## ファイル構成

```
web-pen-red/
├── manifest.json     Manifest V3 定義（action / content_scripts / icons）
├── background.js     ツールバーアイコンのクリックを content script に伝えるだけの service worker
├── content.js        canvas オーバーレイの描画ロジックとミニツールバーの生成・制御
├── content.css       ミニツールバーとオーバーレイのスタイル
├── icons/
│   ├── icon16.png / icon48.png / icon128.png   拡張機能アイコン
│   └── pen.svg / cursor.svg / trash.svg / close.svg
│                     ツールバー内アイコンのソース。ページ側の CSP の影響を受けず
│                     追加リクエストも発生しないよう、content.js 内にインライン展開している
└── README.md
```

## 設計メモ

- 描画点は**ドキュメント座標**で保持し、canvas 自体はビューポート固定サイズ。スクロール時に `requestAnimationFrame` で再描画するため、長いページでも canvas のメモリを消費しません。
- `devicePixelRatio` に合わせて canvas を拡大しているので、高 DPI ディスプレイでも線がぼけません。
- ページ側の CSS に負けないよう、オーバーレイの重要なプロパティは `!important` 付きの ID セレクタで指定しています（`z-index: 2147483647`）。

## スコープ

この拡張機能は意図的に最小限です。色変更・線幅変更・図形・undo・保存・共有などは実装しません。
